# config

Configuración del proyecto.

- **Software:** R 4.5 y Quarto (con TinyTeX para generar el PDF).
- **Paquetes de R:** `readxl`, `dplyr`, `readr`, `tidyverse` (incluye `ggplot2`), `scales` y `shiny`.
- **Parámetros del ejemplo ilustrativo** (definidos al inicio de `cod/04_Modelo_migracion.R`): edad actual 22 años, emigración a los 27 años y estancias de 5 y 20 años en el extranjero.
- **Año de las tablas de mortalidad:** 2023 (definido en `cod/02_Filtro_tablas_mortalidad.R`).

El proyecto no usa credenciales ni datos confidenciales.
