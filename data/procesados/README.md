# data/procesados

Datos filtrados a partir de los originales. Se regeneran corriendo los scripts de `cod/`; no se editan a mano.

- `destinos_principales_2020.csv`: ranking de destinos de la emigración costarricense en 2020, con el código M49 de cada país (`01_Filtro_mayor_migracion.R`).
- `tablas_mortalidad_2023.csv`: tablas de vida 2023 por edad simple (0 a 100+) y sexo de Costa Rica y los cinco principales destinos (`02_Filtro_tablas_mortalidad.R`).
